# Contributing to American Scanner

Thanks for helping improve the project.

## Local setup

```bash
npm install
npm run dev
```

## Before opening a change

Run the checks available in the project:

```bash
npm run lint
npm run build
```

Keep pull requests focused, describe the user-facing impact, and include screenshots when a UI change is involved.

## Commit guidance

Use concise commit messages that explain the change, for example `Improve scanner result layout` or `Document local setup`.
